# Interview-Portraits

Portraitfotos der Interviewpartnerinnen und -partner.

- Dateiname = `slug` aus `components/magazin/interviewData.js`, z. B. `anna-rossi.jpg`
- Hochformat, ca. 900 × 1200 px (4:5) — die Sektion schneidet auf `aspect-[4/5]`
- JPG, unter ~250 kB
- Gesicht eher ins obere Drittel, damit der runde Thumbnail in der Leiste sitzt

Nach dem Ablegen den Pfad im Eintrag als `portrait: { src: "/img/magazin/interviews/<slug>.jpg", alt: "..." }` hinterlegen.
